# MathNotes 0.3.4 逐项验收表

这份表覆盖前后两轮 Windows、Android、PWA 需求，供你逐项自己验。某项“已实现/已测”与“你的真机已通过”是两回事，最后一列留给你记录。

## 开始前

- 从 [0.3.4 发行页](https://github.com/theincrediblewwz/MathNotes-OpenSource/releases/tag/v0.3.4) 下载；Windows 退出旧版后运行新目录里的 EXE，Android 安装 0.3.4/code17。PWA 重新加载并确认连接的是新版电脑宿主，设置应显示 0.3.4。
- 新建一份测试笔记，准备多个块、大小标题、一个锁定块，以及一张边缘有文字、内部有图形的照片。重命名、删除等操作优先用测试笔记。
- 涉及识别/AI 的项目使用你已经配置的识别服务；电脑同步项目先保持配对和目标笔记有效。
- 每项可以填写“通过 / 失败 / 未测”。反馈时直接说编号、设备和现象即可，例如：“M03，安卓电脑同步阅读，点开目录后不能滚动”。

## 仍未完成真机验收的项目

Vivo 厂商高倍率画质和后台策略、真实大照片处理耗时、真实大型笔记库启动速度、Safari/Mac 真机、新 Mac 安装包。以上不能因为代码已实现或模拟器已通过而替你打勾。

四个无上下文独立 Agent 对 8 张合成图片做过遮盖识别实验，没有读出遮盖文字或把遮盖误当图形；样本太少，不能证明某种颜色一定更好。白色矩形方案的确定性保障是上传前替换像素，模型如何描述空白仍有不确定性。
