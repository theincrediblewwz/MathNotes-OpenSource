# MathNotes 0.3.4 试用版

本版整合 Windows、Android、PWA 的阅读、照片编辑和试用反馈修复。公开和私有仓库的最新整合分支均为 `codex/release-v0.3.4-integration`。保留旧发行包与公开历史，已发布的 Mac 接手代码也包含在整合源码中。

## 本次修复

- Windows 拖动块后原地放下、取消或放到空白区域，不再误报 Markdown 导入失败。
- Windows 重新识别会实际发起新请求；等待期间保留原稿，失败、取消和锁定不会覆盖原文。不同笔记的同号任务互不干扰。
- Android/PWA 已上传队列可预览完整的实际上传素材。被清理的本地副本可从已配对电脑取回并校验；识别完成后可以跳到正文中真实照片或转写块。
- Android 本机阅读、电脑同步阅读与 PWA 都提供左上角小目录按钮，点击弹出可滚动圆角气泡。展开不挤动正文，选择标题后跳转并收起。
- 轻点阅读正文显隐底部四个按钮；滚动、选择文字、图片、链接和目录操作各自独立。
- 马赛克放入画笔菜单，使用白色矩形替换被遮盖像素；预览、裁剪/旋转/透视后的上传成品保持一致。旧黑色遮盖继续兼容。
- Android 上传不依赖公网连通性验证；完全无网络时等待重试，不消耗素材的自动重试次数。恢复网络可由系统重新唤起待传任务，保留实际失败退避与重试上限；手动暂停不会被恢复任务重新启动。系统明确拒绝前台上传通知服务时可继续有界后台上传，避免停在“上传中”。

相较旧公开 0.3.1，整合分支还包含 Windows 启动优化、最近阅读重命名/删除、四行块拖动预览、带锁保护的 AI 全文修改、圆角目标选择，以及 Android 原相机拍摄后导入、中文笔记本名称、图片裁剪与处理改进。图形识别内容中支持显示整张处理后照片并点开放大。

## 下载与使用

- Windows ZIP：解压整个目录，退出旧版后运行 `MathNotes.exe`，设置应显示 0.3.4。
- Android APK：版本 0.3.4、versionCode 17，沿用旧测试签名，可覆盖对应测试版。升级前请备份笔记。
- PWA ZIP：包含静态网页、PWA 源码、限定范围补丁、校验脚本与 `MAC_CODEX_HANDOFF.md`。Windows 便携包已经内置新版网页。
- `SHA256SUMS.txt`、发行清单和 Windows/Android CycloneDX SBOM 用于核验下载内容与依赖。

## 验证与限制

Windows 成品 EXE、Chromium 和 Android 模拟器使用合成笔记与受控测试 Provider 验证，不读取生产笔记或调用用户的付费识别配置。Android 完整端到端通过正常电源重启和两轮真实断网恢复：任务进入一小时测试退避、应用进程退出后，仅恢复网络，分别约 6.1 秒收到电脑回执。系统日志确认由网络通知唤起，照片仍保留；此计时来自测试模拟器，不是所有真机的时间保证。详细计数及成品来源记录在发行附件中。

遮盖实验由四个无上下文独立识别 Agent 读取 8 张合成图片完成：本次没有把遮盖误认为图形，真实三角形也保留。这不能证明白矩形优于其他颜色或所有模型都不会误判；采用白矩形主要便于核对遮盖边界。

Windows 是未签名便携测试包，APK 使用测试签名。本版是试用发行，不能视为正式签名版、商店版或已覆盖全部真机矩阵。Vivo 厂商高倍率画质、真实手机大照片处理耗时、用户真实笔记库性能、Safari/Mac 真机仍需复测。完整原相机入口采用打开原相机、拍完返回后选择照片导入的流程；快捷拍照仍保留。

本次不附 Mac 安装包。Mac 源码和交接文件保留，由 Mac 上正在进行的任务完成本地构建。独立 PWA ZIP 不包含 Core；旧 Mac 宿主仍需按交接文件合入上传状态与正文锚点接口，才能完整支持取回素材和准确跳转。
