# Mac 连接诊断

1. 将整个 ZIP 传到出现问题的 Mac，解压。
2. 双击 `diagnose_macos_connection.command`，选择你平时打开的 `MathNotes.app`。
3. 等待约 5–40 秒，把“请复制下面的诊断结果”与“诊断结束”之间的文字复制回来。

如果双击不能运行，可打开“终端”，输入 `bash `（末尾留一个空格），把 `.command` 文件拖进去，再按回车。无需修改系统安全设置。

诊断只读取所选应用包的版本、签名和连接组件，并用系统临时空目录测试本地核心与手机连接服务。不会读取笔记、钥匙串或现有连接凭据，不会修改代理、VPN、Tailscale、防火墙或其他联网设置。它只停止自己启动的测试进程；正常结束后移除自己的临时空目录。不会访问外部网站或调用 AI 模型。

`matchesFc89178` 用来区分同名的 0.2.0 包。`ready` 只表示临时测试启动成功，不能证明应用在用户现有目录、Finder 安全环境或真实手机上也成功。这是诊断工具，不是修复后的 MathNotes 安装包。
